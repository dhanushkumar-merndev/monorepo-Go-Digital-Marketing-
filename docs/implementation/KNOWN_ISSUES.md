## Resolved during the post-Phase-5 architecture audit

| Issue                                                                                                | Resolution                                                                                                                                                                                         |
| ---------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A signed WhatsApp payload was routed by connection key without verifying payload WABA/phone identity | The WhatsApp adapter now rejects a mismatched WABA or `metadata.phone_number_id`; a provider-boundary regression test covers the cross-tenant phone case.                                          |
| Template variables were accepted without exact approved-placeholder matching                         | Shared contracts require numbered, non-empty variables and the backend compares the exact placeholder set before sending; web/mobile render the required fields.                                   |
| Concurrent outbound retry workers could dispatch the same pending record                             | Dispatch now uses one atomic conditional outbox claim, increments attempts at claim time and schedules recoverable delayed jobs; concurrent-job integration coverage proves one provider send.     |
| Stale provider failure events could overwrite a later read state                                     | Projection now orders append-only status history deterministically by provider occurrence, receipt and ID before selecting current state.                                                          |
| Inbox unread counts had no read command                                                              | A scoped, audited `POST /v1/messaging/conversations/:id/read` route clears unread state atomically.                                                                                                |
| Shared inbox workflow state had no canonical web/mobile policy or reset boundary                     | Separate non-persisted Zustand stores now own transient composer/panel state and reset on authentication/tenant/support context changes; server and durable offline state stay outside the stores. |
