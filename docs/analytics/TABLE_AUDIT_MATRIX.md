## Intentional non-pagination decisions

The non-paginated entries above are limited to fixed enums/checklists, single-record detail histories,
per-user authentication state, dealership hierarchy/configuration, provider-limited configuration,
or aggregate client rows. They are not transactional feeds. The account audit view is explicitly a
latest-100 preview; the complete audit surface is the paginated `/reports` table. Pagination must be
added if any fixed/configuration contract becomes a general transactional collection.

## Audit totals

- Surfaces audited: 48.
- B/high-volume surfaces backed by server page or cursor pagination: 20 (including web/mobile views
  sharing endpoints).
- Cursor surfaces: 2.
- Virtualized surfaces: 1 web message timeline; native message rendering remains incremental.
- Network-search surfaces: 3; Lead and conversation search debounce by 300 ms, while inventory uses
  an explicit submitted URL search.
- Exportable surfaces: Lead/report domains through permission-scoped server export jobs; no browser
  export bypass exists.
